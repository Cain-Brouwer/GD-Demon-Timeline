# 3D Demon Timeline

An interactive 3D Geometry Dash demon timeline built with React, Three.js, and Supabase.

**Live → [gd-demon-timeline.netlify.app](https://gd-demon-timeline.netlify.app/)**

## Highlights

- Demons rendered on a spatial timeline with glowing connection threads
- Click any demon for details — difficulty, progress, YouTube showcase
- Create an account to save your timeline to the cloud
- Add, insert, and remove custom demons through the UI
- Sound-only YouTube player with volume fade-in
- 3D starfield void with floating particles
- Camera animations: fly-to and view-all

## Stack

React 19, Three.js (@react-three/fiber, drei), Zustand, Supabase, Vite
